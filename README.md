## MVP 是什么

一个只做一件事的工具：

1. 写一条预测（内容 + 预期达成度 0–100 + 类别 + 截止）
2. 做完填实际值
3. 看三个数字：平均 ΔR、平均绝对偏差、Brier 分数
4. 看校准曲线：你说的 vs 实际发生的

数据存本机浏览器，可导出 JSON。
